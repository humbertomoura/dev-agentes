# Fase 0 · Preparar o ambiente

**Módulo 1 · De chatbot a agente** · branch `main`

1. Instale JDK 21, Git e IntelliJ IDEA e configure uma conta elegível do Antigravity Free com antecedência.
2. Clone `https://github.com/humbertomoura/dev-agentes` e abra a pasta no IntelliJ.
3. Execute `./mvnw test` e `./mvnw spring-boot:run` no terminal da IDE.
4. Abra o Antigravity na raiz do repositório, no app/integração ou CLI disponível.
5. Solicite: “Explique em 3 frases o que este projeto faz. Não modifique arquivos.”
6. Compare a resposta com os arquivos de código.

Referência do projeto original: 13 testes no estado inicial. Se variar, registre o resultado; não altere testes para forçar esse número.

**Pronto quando:** build/testes verificáveis, projeto aberto no IntelliJ, sessão do agente funcional sem alteração de arquivos.
